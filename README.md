# 사방넷 경쟁사 광고 모니터

사방넷(다우기술 이커머스 통합관리 솔루션)의 경쟁사가 **지금 어떤 광고를 돌리고 있는지**를
공개 소스에서 관측해 한 화면에 모아 보는 도구입니다.

기본 등록 경쟁사 — 플레이오토 · 이지어드민 · 넥스트엔진 · 샵링커 · 셀메이트
(화면에서 추가·수정·삭제할 수 있고, 목록은 브라우저에 저장됩니다.)

## 화면

| 탭 | 보는 것 |
|---|---|
| **개요** | 경쟁사별 집행 강도, 네이버 파워링크 관측, 블로그·카페 상위 주제, 운영 중인 메타/구글 광고 소재, AI 경쟁 인텔리전스, AI 카피 전략 리포트 |
| **소재 모아보기** | 등록한 경쟁사 전체의 메타 광고 소재를 한 화면에 나란히 + AI 경쟁군 교차 인사이트 |
| **키워드·콘텐츠** | 키워드 검색량·경쟁도·기기/성별/연령·요일/시간대, 네이버 노출 섹션, YouTube 상위 영상, 블로그·카페 글 |

우측 하단 **AI 분석** 버튼은 위에서 관측한 경쟁사 데이터를 그대로 컨텍스트로 넣어 질문에 답합니다.

## 데이터 출처

모두 공개된 광고·검색 지면에서 관측합니다. 경쟁사의 성과(매출·전환)는 알 수 없으므로
화면에서도 성과로 단정하지 않고 **관측 사실**로만 표기합니다.

- 메타 광고 라이브러리 — 운영 중인 소재, 집행 일수
- 구글 광고 투명성 센터 — 디스플레이 소재
- 네이버 검색 — 파워링크 노출, 블로그·카페 문서
- 네이버 검색광고·데이터랩 — 검색량, 기기·성별·연령 분포
- YouTube Data API — 키워드 상위 영상

## 배포

Vercel에 그대로 올리면 동작합니다(정적 `index.html` + `api/` 파이썬 서버리스 함수).

### 환경변수

없어도 화면은 뜨고, 연동한 것만 실데이터로 채워집니다.

| 변수 | 쓰이는 곳 |
|---|---|
| `ANTHROPIC_API_KEY` | AI 인텔리전스 · 카피 전략 리포트 · 챗봇 |
| `APIFY_TOKEN` | 메타/구글 광고 소재 실시간 조회 |
| `FIRECRAWL_API_KEY` | 네이버 파워링크 관측 |
| `NAVER_DEV_CLIENT_ID` / `NAVER_DEV_CLIENT_SECRET` | 블로그·카페 문서, 데이터랩 |
| `NAVER1_CUSTOMER_ID` / `NAVER1_API_KEY` / `NAVER1_SECRET_KEY` | 키워드 검색량 |
| `YOUTUBE_API_KEY` | YouTube 상위 영상 |

`data.json`은 키워드 탭의 사전수집 스냅샷 자리입니다. 비어 있으면 매번 라이브 API로 조회합니다.
